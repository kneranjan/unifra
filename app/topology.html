Why is the graph blank?
The Unifra database currently has 0 discovered hosts, 0 network links, and 0 containers. This is because no network scan has been run yet. The topology graph only shows data after the Discovery Agent scans your local network via Nmap, PySNMP, and Docker SDK and stores results in PostgreSQL.

Fix it — run a scan:

  1. Open a terminal and navigate to your UNIFRA project folder.
  2. Activate the virtual environment:
    venvUnifra\Scripts\activate
  3. Run the discovery agent:
    python -m app.discovery_agent.scan
  4. Wait for the scan to finish, then click Retry below.

↻ This page auto-retries every 30 seconds. Once scan data is in the database, the graph appears automatically.
